# Todo-List
A simple and efficient command-line To-Do List application built with Python. This project allows users to create, view, update, and delete tasks directly from the terminal. It's lightweight, beginner-friendly, and works entirely offline — perfect for quick personal task tracking.

## Installation:

1. Clone the repository:

    ```bash
    https://github.com/kashyap-parmar/Todo-List.git

2. Navigate to the project folder:

    ```bash
    cd Todo-list

3. Create a virtual environment (Optional):

    ```bash 
    python -m venv venv
    venv\Scripts\activate   # Windows

4. Run the app:

    ```bash 
    python main.py

## Dependencies

- Python 3.x
- (No external packages required)
